# Fontes do Flow

Os ponteiros e o preview foram produzidos para o módulo Flow a partir da
especificação aprovada. Os PNGs derivados em
`faces/flow/src/main/res/drawable-nodpi/` são exportações determinísticas desses
SVGs.

O glifo provisório avaliado durante o desenvolvimento foi removido do mostrador
e das fontes por decisão do mantenedor. Os SVGs restantes são criações originais
do projeto sob GPL-3.0-only. O APK não contém nome, logotipo ou ícone GNOME.
