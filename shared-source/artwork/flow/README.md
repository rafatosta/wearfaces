# Fontes do Flow

Os ponteiros, o preview e a reconstrução vetorial do glifo foram produzidos
para o módulo Flow a partir da especificação aprovada. Os PNGs derivados em
`faces/flow/src/main/res/drawable-nodpi/` são exportações determinísticas desses
SVGs.

O glifo é provisório e foi reconstruído a partir da referência fornecida pelo
mantenedor. A autoria/licença da referência precisa ser formalizada antes de
uma distribuição pública. O APK não contém nome, logotipo ou ícone GNOME.

Os demais SVGs são criações originais do projeto sob GPL-3.0-only.
