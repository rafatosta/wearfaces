# Fontes do Aurora

Os SVGs deste diretório são criações originais do projeto, licenciadas sob
GPL-3.0-only. Os PNGs derivados em `faces/aurora/src/main/res/drawable/` são
renderizados desses arquivos porque o runtime e o avaliador WFF esperam assets
bitmap para ponteiros. Toda inclusão futura deve registrar autoria e licença.
